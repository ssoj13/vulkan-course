## What runs Vulkan, and what develops it

Two different things are easy to confuse:

- **The Vulkan runtime** comes with your GPU driver. It includes the **loader** (`vulkan-1.dll` on Windows) and the
  driver itself. Every user of your program needs it, and they already have it if their driver is recent.
- **The Vulkan SDK** (from LunarG) is for developers: headers, the **validation layers**, shader compilers (`slangc`,
  `glslc`, `dxc`) and tools. Users of your program do not need it.

## Install

<Steps>

1. Update your GPU driver.

2. Install the Vulkan SDK from [vulkan.lunarg.com](https://vulkan.lunarg.com). The course was built with
   SDK **1.4.341.1**. The installer sets the `VULKAN_SDK` environment variable.

3. Check that Vulkan works: run `vulkaninfoSDK` (from the SDK's `Bin` folder) with `--summary`. It lists your GPUs and
   the Vulkan version each one supports.

4. Open **Vulkan Configurator** (`vkconfig-gui`, or `vkconfig gui` from a terminal). It can switch validation layers
   on for any Vulkan program without changing its code. We will use it in lesson 7.

</Steps>

## The example programs

Each lesson step is a small, complete program in two languages. The files repeat everything from previous steps, so
one file always shows a whole working program.

<Tabs syncKey="code-lang">
<TabItem label="Rust (ash)">

[`ash`](https://crates.io/crates/ash) is a thin Rust binding: every Vulkan function and struct maps one-to-one, with
builder methods for the structs. It loads `vulkan-1.dll` at runtime, so building needs no SDK.

```sh
cd examples/rust
cargo run --bin 01_instance
```

</TabItem>
<TabItem label="C++ (Vulkan-Hpp)">

[Vulkan-Hpp](https://github.com/KhronosGroup/Vulkan-Hpp) is the official C++ binding from Khronos and ships with the
SDK. We use its **RAII** layer (`vk::raii::*`): objects destroy themselves when they go out of scope. The official
Khronos tutorial uses the same style.

```sh
cd examples/cpp
cmake --preset msvc-debug
cmake --build --preset msvc-debug
.\build\msvc-debug\01_instance.exe
```

Run these from a shell where the MSVC compiler `cl.exe` is available (a Developer PowerShell).

</TabItem>
</Tabs>

You should see the Vulkan version of your loader, a list of about twenty instance extensions, and
`VkInstance created`. The next lesson explains every line of it.

<Aside type="note" title="Why API version 1.4">
Both programs ask for Vulkan **1.4**, the current version (the official Khronos tutorial uses it too). Two features we
rely on everywhere have been core since 1.3: *dynamic rendering* (drawing without render-pass objects) and
*synchronization2* (clearer barriers). 1.4 adds more to the core, such as push descriptors and the maintenance5/6
improvements. The last crates.io release of `ash` (0.38, 2024) stops at Vulkan 1.3, so the Rust examples use `ash`
from its GitHub repository, pinned to one commit that covers Vulkan 1.4; we switch to the next release once it is out.
</Aside>
