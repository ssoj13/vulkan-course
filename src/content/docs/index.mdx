## Who this is for

You know graphics from the artist's or tools side: Maya, Houdini, shaders, maybe some OpenGL. Vulkan feels like a
wall of structs. This course takes it apart one brick at a time, and every new idea is tied to something you already
know from CG.

<CardGrid>
	<Card title="See it" icon="puzzle">
		Mind maps of every concept and an interactive map of all Vulkan objects; the frame and synchronization modules
		add step-through animations.
	</Card>
	<Card title="Run it" icon="laptop">
		Each step is a small, complete program in **Rust (ash)** and **C++ (Vulkan-Hpp)**. The code in the lessons is cut
