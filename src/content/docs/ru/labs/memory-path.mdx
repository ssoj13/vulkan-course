У дискретного GPU своя память, а всё остальное лежит по ту сторону шины. Лаборатория отвечает на один вопрос:
**сколько стоит кадр, если данные лежат не там?** Теория — в уроке [Что такое GPU](lesson:gpu#своя-память).

Задайте, сколько данных кадр читает или пишет, и выберите путь:

- **GPU читает VRAM** — память на самой видеокарте, около 912 ГБ/с у RTX 3080 Ti, на которой написан курс;
- **GPU читает системную память через PCIe** — буфер остаётся в оперативной памяти компьютера, и GPU забирает его
  через шину PCIe 4.0 x16, около 32 ГБ/с;
- **CPU пишет в окно BAR** — CPU пишет прямо в ту часть VRAM, которую может отобразить к себе в адресное
  пространство, и тоже через PCIe.

Полоса сравнивает один проход по данным с 16,7 мс кадра на 60 fps. Под ней — настоящие кучи (heaps) и типы памяти
GPU курса в том виде, как их выдаёт `vulkaninfo`, и подсвечен тип, который достанется выбранному пути. Выбирается он
так, как советует спецификация Vulkan: первый по индексу тип памяти, у которого есть все нужные флаги.

Обе пропускные способности — теоретический пик, а время — просто байты, делённые на пропускную способность, за
один проход. Реальные передачи до пика не дотягивают, кэши и задержки не учтены, но суть в соотношении: между двумя
путями разница почти в 30 раз.

Что попробовать:

- 64 MiB из VRAM, а потом те же 64 MiB из системной памяти: байты те же, цена почти в 30 раз выше;
- 1 GiB через PCIe: один проход уже не помещается в кадр;
- окно BAR и 256 MiB: не помещается вообще. Без Resizable BAR этот GPU открывает CPU окно в VRAM всего на 214 MiB,
  поэтому данные обычно заливают через staging-буфер и копирование.
