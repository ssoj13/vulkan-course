Every Vulkan object is made from a parent and must be destroyed before it. Try it: create the objects of the first
section in any order, destroy them in any order, and read what the simulator says. Wrong orders get the exact text
of the validation rule (VUID) the real validation layer would report. The rules are explained in
[the logical device lesson](lesson:logical-device) and [the map of Vulkan objects](lesson:object-map).

Things to try:

- create the device before the physical device;
- create the debug messenger without enabling `VK_EXT_debug_utils` on the instance;
- destroy the instance while the device is still alive;
- destroy the queue.
